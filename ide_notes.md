# Git в VS Code

Панель Source Control в VS Code позволяет увидеть изменённые файлы, открыть diff, добавить изменения в staging area и создать коммит.

В diff удалённые строки показываются красным, а добавленные — зелёным. Графический интерфейс удобен для просмотра изменений, но основные Git-команды также важно уметь выполнять в терминале.
