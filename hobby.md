# Мой пет-проект

**Идея:** телеграм-бот «Мой гардероб» - помогает собирать аутфиты из своей одежды. Пользователь фотографирует вещи, бот распознаёт категорию (верх, низ, обувь, аксессуар), цвет и стиль, сохраняет их в личный виртуальный шкаф и предлагает готовые образы под погоду, повод и настроение.

**Стек:** Python (aiogram), PostgreSQL, Pillow, scikit-learn (или готовый API для распознавания), Docker.

**Цель:** научиться писать асинхронных ботов, работать с изображениями и базой данных, а также упаковывать приложение в Docker-контейнер.

**План развития:**
1. MVP — команда `/add_photo` принимает фото вещи, сохраняет в БД и просит указать категорию вручную.
2. Автоматическое распознавание категории и цвета по фото (ML-модель или внешний API).
3. Команда `/outfit` — бот предлагает случайный образ из вещей пользователя.
4. Учёт погоды: интеграция с OpenWeatherMap, чтобы бот не предлагал шорты в −10 °C.
5. Социальная часть — возможность делиться аутфитами с друзьями прямо в Telegram.
